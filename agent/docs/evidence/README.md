broker truth, executable configuration or current-checkout test assertions.
They remain at stable paths so acceptance reports and research lineage stay valid.

Do not overwrite a receipt after changing code, fees or data. Add a newly dated
record with explicit lineage. Raw datasets, credentials, runtime databases and
private host paths do not belong here.
